# AmyxAnvil 1.0.2

Исправлено получение результата: предмет больше не отклоняется из-за обозначения слота `ANVIL_RESULT_PREVIEW` в запросе Bedrock. Предыдущая версия принимала только `CREATED_OUTPUT`, из-за чего клиент возвращал результат обратно.

- Оба обозначения используют один и тот же конечный результат, рассчитанный сервером.
- Поддерживаются обычное получение на курсор и быстрый перенос в инвентарь после переименования, ремонта и переноса чар.
- Сервер явно подтверждает очистку виртуального слота результата.
- Проверены разделение стака и попытки повторно получить результат через другое обозначение слота. Материалы и опыт списываются один раз; отклонённая операция их не меняет.

Сначала новые проверки воспроизвели отказ на версии 1.0.1. После исправления проверено 108 сценариев на официальных PMMP 5.0.0 и 5.44.3: 21 проверка правил и 33 серверные операции на каждой версии. Ручной прогон графического Bedrock-клиента не проводился.

Для установки распакуйте `AmyxAnvil-install.zip` в папку остановленного сервера либо поместите `AmyxAnvil.phar` в `plugins/`. Зависимости не нужны. Исходники — `AmyxAnvil-source.zip`. Контрольные суммы — `SHA256SUMS.txt`.
