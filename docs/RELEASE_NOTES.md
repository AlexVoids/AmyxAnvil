# AmyxAnvil 1.0.4

Убрано использование внутреннего буфера крафта и общего обработчика рецептов ядра для операций AmyxAnvil. Это исключает вызов, возвращавший `Not all of the previous created item was taken` в присланном журнале NG-PocketMine-MP 5.39.1.

- Плагин сам учитывает оставшееся количество рассчитанного результата. `CREATED_OUTPUT` и `ANVIL_RESULT_PREVIEW` делят один результат, получить лишний предмет нельзя.
- Разрешённый перенос обрабатывается самим плагином. Сохранены штатные проверки окна, контейнера, слота и сетевых идентификаторов ядра.
- Книга, исходный предмет и опыт списываются только при успешной полной транзакции. Неполное получение стака отклоняется без потери предметов.
- В тесты добавлены три последовательности из журнала пользователя: материал перед исходным предметом, `Place` из контейнера 60 / слота 50 с отрицательным ID запроса в объединённый инвентарь 12 / слоты 7 и 8.
- Журнал отказов теперь показывает название и полную версию ядра, строку ошибки и количество предметов во входах. Поле `server` содержит версию Minecraft, а не ядра.

Проверено 198 сценариев на официальных PMMP 5.0.0, 5.28.0 и 5.44.3: по 21 проверке правил и 45 серверным сценариям. Дополнительно 45 серверных сценариев прошли на PMMP 5.44.3 с публичным классом обработчика NG, без запуска полного форка. Точная пользовательская Windows-сборка NG 5.39.1 и графический Minecraft-клиент не запускались. Запросы из журнала не воспроизводят отказ на обычном PMMP 1.0.3; исправление устраняет зависимость от внутреннего состояния буфера ядра.

Установка: остановите сервер, замените **единственный** `plugins/AmyxAnvil.phar` новым файлом и запустите сервер. Не используйте `/reload`.

Файлы: `AmyxAnvil.phar`, `AmyxAnvil-install.zip`, `AmyxAnvil-source.zip`, `SHA256SUMS.txt`.
