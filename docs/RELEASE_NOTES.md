# AmyxAnvil 1.0.0

Первый самостоятельный релиз для PocketMine-MP 5.x: обычная наковальня со штатным окном Bedrock.

- Переименование и очистка имени, ремонт материалами и одинаковыми предметами.
- Зачарованные книги, перенос и повышение чар, проверка совместимости.
- Стоимость в уровнях опыта по правилам Bedrock, штраф прошлых работ, ограничение стоимости.
- Износ и разрушение блока, звуки, возврат неиспользованных предметов при закрытии.
- Проверка серверного результата и сетевых стеков, защита от повторного получения результата.
- Совместимость с ранними PM5, включая регистрацию отсутствующей зачарованной книги.

Проверено 90 сценариев на официальных PMMP 5.0.0 и 5.44.3: 21 проверка правил и 24 серверные операции на каждой версии. Ручной прогон графического Bedrock-клиента не проводился. Эффекты чар за пределами наковальни зависят от поддержки самого ядра; подробнее в README.

Для установки распакуйте `AmyxAnvil-install.zip` в папку остановленного сервера либо поместите `AmyxAnvil.phar` в `plugins/`. Зависимости не нужны. Исходники — `AmyxAnvil-source.zip`. Контрольные суммы — `SHA256SUMS.txt`.
