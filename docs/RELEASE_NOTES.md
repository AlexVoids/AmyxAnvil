# AmyxAnvil 1.0.3

Исправлены дополнительные причины отказа при получении результата, в том числе при наложении чар с зачарованной книги в Minecraft 1.21.80.

- Если клиент не прислал отдельные `Consume`, сервер сам формирует списание входного предмета и нужного количества материала в общей транзакции. Явно присланные количества и сетевые идентификаторы проверяются.
- Поддержан перенос результата через курсор внутри одного запроса. Промежуточная копия не остаётся в расчёте; конечные слоты учитываются один раз.
- Получение из слота результата обрабатывается и без отдельного маркера рецепта.
- После подтверждения запроса отправляется полный предмет с NBT чар, именем и прочностью. Сетевые идентификаторы сохраняются, чтобы следующий перенос не откатывался. Учитывается конечный инвентарь во всём пакете запросов.
- Добавлен ограниченный журнал отказов `plugins/AmyxAnvil/anvil-errors.log` и сообщение в консоли, чтобы определить причину отказа в конкретной сборке.

Новые проверки сначала воспроизвели пять отказов версии 1.0.2. После исправления выполнено 186 проверок: по 21 проверке правил и 41 серверному сценарию на PMMP 5.0.0, 5.28.0 и 5.44.3. На 5.28.0 запрос и ответ зачарования, а также полный предмет проверены через сериализацию протокола Minecraft 1.21.80. Графический клиент в среде не запускался.

Установка: **остановите сервер**, замените единственный `plugins/AmyxAnvil.phar` новым файлом и запустите сервер. Исходники — `AmyxAnvil-source.zip`, установка архивом — `AmyxAnvil-install.zip`, контрольные суммы — `SHA256SUMS.txt`.
