# AmyxAnvil

Нативная наковальня для **PocketMine-MP 5.x / Minecraft Bedrock**. Отдельный плагин, разработанный с нуля. Использует обычный блок и стандартное окно наковальни клиента; FormAPI, InvMenu, экономика и ресурс-паки не нужны.

В **1.0.2** исправлено возвращение предмета в слот результата: поддерживаются оба обозначения результата Bedrock, обычное получение на курсор и быстрый перенос в инвентарь. При обновлении замените старый `AmyxAnvil.phar` и полностью перезапустите сервер.

## Скачать и установить

1. Скачайте [AmyxAnvil-install.zip из последнего релиза](https://github.com/AlexVoids/AmyxAnvil/releases/latest).
2. Остановите сервер, распакуйте папку `plugins` из архива в папку сервера.
3. Запустите сервер. В консоли должна появиться строка `Нативная наковальня включена`.
4. Поставьте обычную наковальню и нажмите на неё. Слева — предмет, справа — материал или зачарованная книга. Переименование вводится в штатное поле окна. Заберите результат, чтобы завершить операцию.

Можно установить один файл [`AmyxAnvil.phar`](https://github.com/AlexVoids/AmyxAnvil/releases/latest/download/AmyxAnvil.phar) в `plugins/`. Исходники находятся в этом репозитории и в `AmyxAnvil-source.zip`. Зависимости устанавливать не требуется.

## Возможности

- Переименование, в том числе на русском языке, и удаление имени пустым полем; до 64 символов.
- Переименование целого стака за одну операцию.
- Починка материалом: одна единица восстанавливает до 25% стандартной прочности. Тратится только нужное количество материала.
- Объединение двух одинаковых повреждённых предметов с бонусом прочности 12%.
- Перенос чар с книг и одинаковых предметов. Одинаковые уровни повышаются на один до ванильного максимума; несовместимые чары отбрасываются, остальные сохраняются.
- Объединение зачарованных книг, сохранение имени, описания и стороннего NBT исходного предмета.
- Стоимость в **уровнях опыта**, правила Bedrock для стоимости чар, штраф предыдущих работ `RepairCost`, ограничение «Слишком дорого!» от 40 уровней в выживании. Переименование без ремонта ограничивается ценой 39 уровней и не увеличивает штраф.
- Творческий режим без списания опыта и износа блока.
- Износ наковальни с вероятностью 12% при успешной операции, три состояния блока, разрушение и стандартные звуки.
- Возврат неиспользованных предметов при закрытии через штатную механику временного инвентаря PocketMine.
- Проверка настоящих входных предметов, количества, актуальности сетевых стеков, окна, расстояния до блока, режима игры и опыта. Сервер сам рассчитывает результат; предмет результата от клиента не принимается на веру.
- Поддержка отмены `InventoryOpenEvent`, `InventoryTransactionEvent` и `PlayerExperienceChangeEvent` другими плагинами.

Доступ: разрешение `amyxanvil.use`, по умолчанию доступно всем. Отдельных команд плагин не добавляет.

## Совместимость и границы

Проверено на официальных **PocketMine-MP 5.0.0 / PHP 8.1.34** и **5.44.3 / PHP 8.4.16**. Поддерживаются старый и новый варианты запросов наковальни и API контейнеров пятой ветки. Все промежуточные версии и сторонние форки отдельно не прогонялись. Для Bedrock-клиента используйте версию, которую поддерживает ваш PocketMine.

В ранних PM5 плагин регистрирует отсутствующий предмет `minecraft:enchanted_book`. Его можно выдать стандартной командой `/give Ник enchanted_book`. После удаления плагина ранняя версия ядра снова перестанет распознавать такие книги; для постоянной работы оставляйте плагин установленным либо обновите ядро.

Для сохранения и объединения чар регистрируются отсутствующие в ядре ванильные идентификаторы. **Эффекты этих чар в бою, добыче, рыбалке и движении определяются PocketMine и другими установленными плагинами.** AmyxAnvil реализует работу наковальни, а не отсутствующие игровые системы ядра. Предметы, которых само ядро не поддерживает, плагин не добавляет. Пользовательские чары используют совместимость, зарегистрированную их плагином; изменение ванильных ограничений не предусмотрено.

Окно и предварительный результат рисует клиент Bedrock. Автоматические тесты используют настоящие классы протокола, предметы, мир, инвентари, опыт и сервер PocketMine; сетевой транспорт игрока заменён тестовым. Ручной прогон в графическом Bedrock-клиенте в этой среде не проводился. Поэтому обещания абсолютной совместимости «100%» со всеми клиентами и сборками нет.

Не устанавливайте одновременно несколько плагинов, которые перехватывают операции одной и той же наковальни.

## Проверка и сборка из исходников

Нужны PHP из комплекта PocketMine, официальный PHAR ядра и Python 3 для упаковки и серверного прогона. Composer и сторонние библиотеки для плагина не требуются.

```bash
PMMP_PHAR=/path/PocketMine-MP.phar /path/php -n tests/rules.php
python3 tools/test-server.py --php /path/php --pmmp /path/PocketMine-MP.phar
/path/php -n -d phar.readonly=0 tools/build.php
python3 tools/package-release.py
```

Серверный прогон создаёт отдельный одноразовый сервер в игнорируемой папке `work/`. Не устанавливайте `AmyxAnvilTests.phar` на рабочий сервер.

Логику можно менять в `src/Amyx/Anvil/rules/AnvilCalculator.php` и `EnchantmentRules.php`; проверку и применение операции — в `transaction/AnvilTransaction.php`; обработку штатного протокола — в `network/AnvilRequestExecutor.php`. Сборка создаёт `build/AmyxAnvil.phar`.
